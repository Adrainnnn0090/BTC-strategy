# 风险定义与未解决问题

## 已知且可重复的历史事实

|指标|分子/分母与计量|不能解释为|
|---|---|---|
|入场预算|新开仓时用净值的一定比例确定数量|持仓全程的gross上限|
|gross|绝对BTC名义价值/当时净权益，含退出前旧仓与退出后新状态|盘中峰值或未来硬上限|
|止损百分比|相对单笔入场basis的风险触发条件|实际成交亏损上限|
|日度最大回撤|连续账户每日净权益相对此前峰值的最大跌幅|单日跌幅、盘中DD或未来承诺|
|正交易集中度|前N笔正PnL/所有正交易PnL|占总净利润或预测有效概率|

LP35在BASE退出前short gross曾达118.0456%，DELAY曾达104.4303%；75%冷空头预算不能当持续敞口帽。其12%空头止损有一笔因延迟及不利价格实际亏损26.6249%入场basis。4%移动止盈是盈利追踪距离，不是4%硬止损。LP35的TP=3.5代表350%，不是35%。

K02降低的是空头预算，整体回撤仍主要由共同多头路径决定。其post=.25的匹配冷预算父对照是L05；L05/L06共用模型，若与L06比较则同时改变cold和post预算。C02/C04只在合资格2020—2025折缩放新开多头预算，2018/2019保持原值，并非全期75%敞口。

## 仍未解决的资格问题

1. 2018—2025是反复消费的开发历史，年度模型前推不使后选规则成为新鲜OOS。九候选、四成本、成员和登记都不是新的独立市场样本。
2. PBO/DSR所需的完整可比候选×时间矩阵与有效选择过程未重建；有效独立试验数保持未知。115份标准登记和非标准合同只用于追溯，不用于制造显著性。
3. 原价格为USD日度参考代理，合成BTCUSDT报价及静态流动性不能认证真实成交、价差、市场冲击和容量。合成时间戳不等于历史发布时间。
4. 融资累计从策略净值、PnL和后续预算扣除，但未进入Native原生钱包；Native有保证金/清算机制，仍不能由此证明真实融资调整后的清算安全。
5. 来源历史vintage/修订、节点时钟及规范链可取得性不完整。C04挖矿列保留lag60/2小时缓冲/100确认与缺失mask，仍是有条件的历史重建，不获严格PIT认证。
6. LP35相对TS04只有一笔退出日改变，后续数量与复利放大资金差异；DELAY方向相反。相邻已登记止盈点只有350%越过历史收益门，不证明邻域稳健或新的预测因子。
