# 六组专家、十二轮隔离审查约定

## Charter

目标：对九项保留BTC策略完成六个AI分析角色各十二次独立提交、十二份主审结论，并在本仓交付分类实现、实际年度数值模型、账户基准与可复现验证入口。这里的专家是模拟分析角色，不是外部人类审计或新的独立市场样本。

范围/对象/对象单元：BTC历史策略研究可信度与复现 / 已冻结的2018—2025候选 / 分集、标签、模型、目标与许可、成本账户、风险、工程导出。

类型：描述性协议与交付设计 → 对已有记录做实验性历史审计。已有深度实现与账本证据，统计泛化和实盘适用性仍未证明。

问题：Q1数值定义是否正确；Q2是否泄漏或误称OOS；Q3模型训练/预测是否一致；Q4执行/费用/融资是否完整；Q5敞口/止损/集中风险是否清楚；Q6导出是否可重建及复现。

2025全部允许开发。年度模型仍只用上一年底前数据，2025折训练2017—2024。2018—2025已被人工规则研究反复使用，不称新鲜OOS。全部2026经济观察禁止进入本轮模型、调参、筛选、检查数据或账户。已有2026验证的状态不因此改写。

## Canonical sources

1. 原始研究登记、年度封印、源码、数值模型与账户；保留精确路径、SHA256、Git提交和原技术失败。
2. 原始方法论文，以及Nautilus/scikit-learn官方文档；最新文档仅为一般原则，精确行为由安装版本和实际代码核对。
3. 只读独立Decimal/数值重建、合成例子和新仓复现检查。
4. 社区解释只作线索，不能单独认证来源PIT、统计显著性或实盘资格。

## Findings ledger

逐轮主审记录引用每位专家的证据，不以多数票代替计算，不将“代码一致”升级成“真实alpha”。共同数据与模型导致的相关意见不算独立市场证据。

## Scope filter

股票估值、ETF持仓与个人投资建议不适用于本次BTC代码审计；Stock & ETF Panel仅贡献盲审、固定事前权重和非投票风险挑战结构。采用六个与本对象匹配的审计角色，不声称运行了股票筛选或获得人类专家背书。

## Object filter

只保留对九项已冻结策略及其复现有直接证据的结论。历史参数比较、累计收益、日度DD、盘中风险、真实融资清算与未来表现分别标识。缺证据保留为未解决项。

## Conclusions

由每轮独占提交完成后，主审读取、复核关键证据并生成，不能事先填充或批量伪造十二轮。

## Next steps / Risks

主agent独占修改交付仓；各专家只能写自己的隔离目录。每轮六项提交齐备才主审并发下一轮，共72项。冻结源证据只读，不运行原研究写入器，不优化策略参数，不执行交易。可验证的工程问题在新仓修复，原源文件与原失败不得改写。
